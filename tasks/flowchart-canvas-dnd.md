# フローチャート・キャンバス化 + D&D + グループ化

## 概要

フローチャートエディタを自由配置キャンバスに進化させる。

- ステップを自由にドラッグ＆ドロップで配置
- **メインフロー** (実行対象) と **フリーエリア** (検証用) の 2 領域
- D&D でグループへの追加 / グループからの取り出し
- 複数選択 → コンテキストメニューでグループ化

## データモデル変更

```typescript
// Step に追加
interface Step {
  // 既存フィールド ...
  /** false のときフリーエリア配置 (実行されない) */
  inFlow?: boolean;       // undefined | true = メインフロー
  /** フリーエリアでの座標 (inFlow=true のときは自動配置で無視) */
  position?: { x: number; y: number };
}
```

- `inFlow` が `false` → フリーエリア。エンジンは無視。
- `inFlow` が `undefined` or `true` → メインフロー。`order` 順に実行。
- メインフロー上のステップは自動レイアウト (従来通り縦列)
- フリーエリアのステップは `position` で絶対配置

## キャンバスレイアウト

```
+--------------------------------------------------------------+
|  [フリーエリア]                                                |
|     ┌──────┐                                                  |
|     │ test │  (inFlow=false, 実行されない)                      |
|     └──────┘                                                  |
|                  ╎                                             |
|                  ╎  ── メインフロー ──                          |
|                  ╎                                             |
|              ┌──────┐                                          |
|              │step 1│                                          |
|              └──┬───┘                                          |
|                 │                                              |
|              ┌──┴───┐                                          |
|              │step 2│                                          |
|              └──┬───┘                                          |
|                 │                                              |
|              ┌──┴───┐                                          |
|              │group │ ← D&D でグループに入れる                   |
|              │ ├ a  │                                          |
|              │ └ b  │                                          |
|              └──────┘                                          |
+--------------------------------------------------------------+
```

- メインフロー: キャンバス中央に縦方向自動レイアウト
- フリーエリア: メインフロー以外の領域に自由配置
- 薄い破線ガイドでメインフロー領域を可視化

## D&D 仕様

### ステップのドラッグ

- mousedown → 3px 移動でドラッグ開始 (BlockView.tsx パターン踏襲)
- ゴースト要素 (半透明コピー) をカーソル追従で表示
- Escape でキャンセル

### ドロップ先

| ドロップ先 | 挙動 |
|-----------|------|
| メインフロー内 (ステップ間) | 挿入位置に order を再計算して挿入 |
| メインフロー内 (先頭/末尾) | 先頭/末尾に挿入 |
| グループ上 | `parentStepId` を設定してグループの子に追加 |
| フリーエリア | `inFlow: false` + `position` を設定 |
| メインフローへ戻す | `inFlow: true (undefined)` + `position` 削除 |

### ドロップインジケーター

- メインフロー: ステップ間に水平線 (青) を表示
- グループ: ハイライト枠 (グループ色)
- フリーエリア: ゴースト要素のみ

## 複数選択

- **Ctrl+Click**: トグル追加
- **Shift+Click**: 範囲選択 (メインフロー内は order 範囲)
- **ラバーバンド** (空領域ドラッグ): 矩形内のステップを選択
- 選択ステップを一括ドラッグ

## コンテキストメニュー (Base UI ContextMenu)

右クリック時:

| メニュー項目 | 条件 | 動作 |
|-------------|------|------|
| グループ化 | 複数選択時 | 選択ステップを新グループにまとめる |
| グループ解除 | グループ選択時 | 子ステップを親に展開 |
| フリーエリアへ移動 | メインフロー上 | inFlow=false にする |
| メインフローへ戻す | フリーエリア上 | inFlow=true にする (末尾追加) |
| 複製 | 常時 | ステップを複製 |
| 削除 | 常時 | ステップを削除 |

## 実装順序

### Step 1: データモデル + キャンバス基盤
- Step に `inFlow`, `position` フィールド追加
- FlowchartEditor をキャンバスレイアウトに変更
- メインフローは従来通り中央縦列
- フリーエリアのステップを絶対配置で描画

### Step 2: 単体ステップの D&D
- FlowchartStepView にドラッグハンドル追加
- ゴースト要素 + カーソル追従
- メインフロー内の並び替え (order 再計算)
- フリーエリアへの移動 / フリーエリアからの復帰

### Step 3: グループ D&D
- グループへのドロップ検出 (hitTest)
- グループからの取り出し
- FlowchartGroupView のドロップターゲットハイライト

### Step 4: 複数選択
- Ctrl+Click, Shift+Click
- ラバーバンド選択
- 選択ステップの一括ドラッグ

### Step 5: コンテキストメニュー
- Base UI ContextMenu でメニュー描画
- グループ化 / グループ解除 / 移動 / 複製 / 削除

## 使用コンポーネント

- D&D: ネイティブ mouse events (BlockView.tsx パターン)
- ゴースト: `createPortal` + `position: fixed`
- コンテキストメニュー: `@base-ui/react/context-menu`
- グループ展開: `@base-ui/react/collapsible` (既存)
